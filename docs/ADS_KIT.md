## 2. Meta (Facebook / Instagram)

**Campaign objective:** Leads (ya Traffic → landing page). Location: Pakistan. Age 18–45. Language: English + Urdu.

**Study abroad — primary text**
- "Study abroad ka plan hai? Pehle apni documents aur options clear karein. Free assessment se start karein."
- "Kahan apply karna hai, kya documents chahiye — sab step by step samjhein. Final decision hamesha relevant authority ka hota hai."

**Headlines (max ~40 chars)**
- "Study Abroad Guidance"
- "Free Visa Options Assessment"
- "Documents Review Before You Apply"

**Description:** "Independent consultancy. Guidance only, no guarantees."
**CTA button:** Learn More / Sign Up

**Visit visa — primary text**
- "Tourist ya family visit visa se pehle apni file check karwayein. Common mistakes se bachein."
- "Kaun se documents chahiye? Official links ke saath clear checklist."

**Interview prep — primary text**
- "Interview se pehle tayari. Apne sach ko clear aur confident tareeqe se bayan karna seekhein. Hum kabhi jhoote jawab nahi sikhate."

**Meta policy reminders:** "guaranteed", "100% visa", "instant approval", before/after claims, aur embassy/government ka naam ya logo use na karein.

## 4. TikTok Ads

**Objective:** Lead generation / Traffic. 15–30 sec vertical video (9:16). Pehle 2 second mein hook.

**Script 1 — Study abroad (UGC style)**
- Hook (0–2s): "Study abroad ka sochte ho? Pehle ye 3 cheezein check karo."
- (2–20s): Text overlay: 1) Apni education documents ready 2) English test ka plan 3) Budget aur funding clear. Presenter har point bolta hai.
- CTA (20–25s): "Free assessment ka link bio / button mein. Guidance only, koi guarantee nahi."

**Script 2 — Visit visa mistakes**
- Hook: "Visit visa reject hone ki aam wajah?" (yahan koi statistic na bolein)
- Points: incomplete documents, inconsistent information, unclear travel plan.
- CTA: "Apni file pehle review karwao."

**Script 3 — Scholarship**
- Hook: "Scholarship dhundne ka asaan tareeqa"
- Show: website par scholarship finder screen recording.
- CTA: "Link mein finder dekho. Selection ka wada nahi, tayari mein madad."

**Captions:** "Study abroad guidance 🌍 Free assessment link mein. Independent consultancy — no guarantees. #studyabroad #visaguidance #pakistan"

## 5. Social media ke liye image / video material

Main images khud generate nahi kar sakta. Neeche har creative ka **size aur prompt** hai; kisi bhi image tool (Midjourney, DALL·E, Canva AI, Ideogram) mein paste karein. Text image ke andar na likhwayein (AI spelling kharab karta hai) — text Canva mein baad mein add karein. Logo aap apna asli logo (`public/brand/logo-full.png`) Canva mein lagayein.

**Common rules:** koi asli embassy/government logo, asli passport nahi, kisi mashhoor shakhs ka chehra nahi, aur "visa stamp approved" jaisa message nahi.
